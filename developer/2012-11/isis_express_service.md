# ISIS express service

*Migrated from the retired Mantid wiki page `Workshop2012_ISIS_express_service`.*

1. user submit express proposal

2. instrument scientist select proposal (which generates Mantid script behind the scene)

3. inst. scien. put sample/standard on beamline

4. process waits for all data needed to run script is available

5. when available generate reduced data and also upload these to Mantid
